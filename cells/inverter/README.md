# Inverter

Cell kiểm chứng toàn bộ flow trước khi nhóm cam kết tiếp tục đề tài.

Definition of Done:

- schematic đúng;
- transient simulation chạy được;
- đo được rise/fall delay và power cơ bản;
- layout DRC clean;
- LVS match;
- extraction thành công;
- post-layout simulation chạy được;
- mỗi thành viên có thể giải thích và tái chạy quy trình.
