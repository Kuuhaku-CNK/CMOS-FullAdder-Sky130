# Configuration

Thư mục này lưu các điều kiện đo đã được nhóm thống nhất, danh sách PVT và cấu hình dùng chung.

- Không thay đổi điều kiện benchmark riêng trên branch mà không ghi vào `docs/DECISIONS.md`.
- Mọi giá trị chính thức phải xuất hiện trong `docs/MEASUREMENT_PROTOCOL.md`.
- Script sweep sau này phải đọc cấu hình từ thư mục này thay vì sao chép giá trị ở nhiều nơi.
