# Consolidated results

Thư mục tổng hợp kết quả chính thức dùng cho bảng so sánh và báo cáo.

Nguyên tắc:

- Raw waveform đặt trong thư mục `generated/` và không commit.
- Commit CSV/TSV đã tổng hợp, script tạo bảng/plot và hình cuối cần cho báo cáo.
- Mỗi dòng dữ liệu phải xác định được architecture, source netlist, corner, VDD, temperature, load và input slew.
- Không chép số thủ công vào báo cáo nếu chưa lưu nguồn dữ liệu tương ứng.
